# Cybersecurity Risk Assessment: Lakeside Medical Center

## Project Overview

This project is a cybersecurity risk assessment for Lakeside Medical Center, a fictional mid-sized healthcare organization with approximately 500 employees across five clinics and a central administrative office.

The assessment evaluates cybersecurity risks associated with the organization's cloud-based Patient Information System, with a focus on protecting the confidentiality, integrity, and availability of sensitive patient information and healthcare systems.

## Objectives

- Identify critical information assets, systems, devices, and user accounts
- Identify potential cybersecurity threats and vulnerabilities
- Evaluate the likelihood and impact of identified risks
- Assign initial risk ratings
- Recommend appropriate security controls
- Evaluate residual risk after implementation of recommended controls

## Key Risks Identified

The assessment evaluated five cybersecurity risks:

1. Malicious external actor compromising a patient check-in tablet
2. Phishing attacks targeting employee accounts
3. Lost or stolen devices
4. Insider misuse
5. Patient Information System failure

## Security Controls Recommended

Recommended controls included:

- Network access controls
- Multi-Factor Authentication (MFA)
- Sender Policy Framework (SPF)
- Cybersecurity awareness training
- Role-Based Access Control (RBAC)
- Attribute-Based Access Control (ABAC)
- Least privilege
- Encryption
- Security Information and Event Management (SIEM)
- System updates and patching
- Load balancing
- System redundancy
